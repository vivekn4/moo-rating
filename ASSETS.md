The cow sprite is used under the CC-BY 3.0 license. Attribution: Daniel Eddeland, with a link to the source page above. The single frame used in the game was cropped from the `cow_walk.png` sheet (right-facing standing cow), trimmed, and scaled to 200 x 150 pixels with a transparent background. The file lives at `assets/sprites/cow.png`.

## Current status

- Cow sprite: in use, credited above.
- Barn: not used. A Red Barn candidate on OpenGameArt was checked and left out because no CC0 or CC-BY license was confirmed for it.
- Grass tile: not used in the game. A CC0 grass tileset was found but the game only loads the cow sprite, so it was not included.
